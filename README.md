# Task 03 – Prompting for Task Automation

## Objective

The objective of this task is to demonstrate how prompt engineering can automate repetitive real-world tasks by converting unstructured text into structured, machine-readable data.

---

## Problem Statement

Businesses often have meeting notes, emails, and discussions in plain text. This project uses AI prompting to automatically extract structured information that can later be used in dashboards, CRMs, or automation workflows.

---

## Prompt Engineering Techniques Used

- Role Prompting
- Output Constraints
- JSON Formatting
- Structured Extraction
- Consistency Rules

---

## Deliverables

- Automation Prompt
- Three Input Examples
- Three Structured Outputs
- Reflection

---

## Skills Demonstrated

- Prompt Engineering
- Task Automation
- JSON Formatting
- Information Extraction
- AI Workflow Design

---

## Conclusion

Prompt engineering enables AI to transform messy, unstructured information into clean, structured data that can be integrated into software systems.
